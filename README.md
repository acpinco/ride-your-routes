# Ride your Routes: feedback

Ride your Routes is an Android app for indoor riding. It connects to a smart trainer and heart rate strap, then lets you ride your own Strava routes with realistic grade and virtual gears.

This repository is only for **bug reports and feature requests**. The app's source code is not published here.

- Found a bug? [Report it](../../issues/new?template=bug_report.yml)
- Have an idea? [Request a feature](../../issues/new?template=feature_request.yml)
- Looking for what changed? See [Releases](../../releases)

Please search existing issues first, and add a thumbs-up to ones you care about.

## Privacy

Don't post personal information in issues. That includes your Strava export, email address, home location, or screenshots showing your name or photo.
